1. String - 회문 (Palindrome)

"기러기", "토마토"처럼 똑바로 읽어도 거꾸로 읽어도 똑같은 문자열을 판별합니다.

💡 핵심 원리: 전체 길이를 순회할 필요 없이, 문자열 길이의 절반(len/2)까지만 순회하며 양 끝에서부터 마주보는 문자가 같은지 비교합니다. 
def is_palindrome(txt):
    n = len(txt)
    # 문자열 길이의 절반까지만 검사
    for i in range(n // 2):
        # 앞쪽 글자와 뒤쪽 대칭되는 글자 비교
        if txt[i] != txt[n - 1 - i]:
            return False # 하나라도 다르면 회문이 아님
    return True

# Test
print(is_palindrome("토마토")) # True
print(is_palindrome("algorithm")) # False

2. Tree - 순회 (Traversal)

비선형 구조인 트리의 모든 노드를 중복 없이 체계적으로 방문하는 방법입니다.

  • 전위 순회 (Preorder, VLR): 부모 방문 → 왼쪽 자식 → 오른쪽 자식
  • 중위 순회 (Inorder, LVR): 왼쪽 자식 → 부모 방문 → 오른쪽 자식
  • 후위 순회 (Postorder, LRV): 왼쪽 자식 → 오른쪽 자식 → 부모 방문
class Node:
    def __init__(self, item):
        self.item = item
        self.left = None
        self.right = None

# VLR
def preorder_traverse(T):
    if T:
        print(T.item, end=' ') # Visit (부모 처리)
        preorder_traverse(T.left)
        preorder_traverse(T.right)

# LVR
def inorder_traverse(T):
    if T:
        inorder_traverse(T.left)
        print(T.item, end=' ') # Visit
        inorder_traverse(T.right)

# LRV
def postorder_traverse(T):
    if T:
        postorder_traverse(T.left)
        postorder_traverse(T.right)
        print(T.item, end=' ') # Visit

3. Stack 연습문제 (구현 및 추적)

LIFO(후입선출) 구조. 코딩 전 종이에 그림을 그려 Push/Pop 상태를 확인하세요.

✍️ 학습 가이드: 빈 배열 []을 그리고, 데이터가 들어올 때 화살표(Top)가 이동하는 모습, 나갈 때 지워지는 모습을 직접 그려보는 것이 구현보다 중요합니다. 
# 파이썬 리스트를 이용한 스택 기본 구현
stack = []

def push(item):
    stack.append(item)
    print(f"Push: {item} -> 현재 스택: {stack}")

def pop():
    if len(stack) == 0:
        return "Stack is Empty"
    item = stack.pop()
    print(f"Pop : {item} -> 현재 스택: {stack}")
    return item

# 추적 연습 (직접 예상해보고 실행 결과와 비교)
push('A')
push('B')
push('C')
pop()
pop()
push('D')

4. Queue BFS 예제 3

너비 우선 탐색. 인접 정점을 큐에 넣고 순서대로 방문합니다.

입력 (V=7, E=8):
1 2 1 3 2 4 2 5 4 6 5 6 6 7 3 7
예상 출력 (시작점 1):
1 2 3 4 5 7 6
✍️ 학습 가이드: visited 배열(방문 체크)과 queue(대기열) 배열 2개를 종이에 그리고, dequeue된 정점의 인접 정점들이 어떻게 enqueue 되는지 한 단계씩 추적해 보세요. 
def bfs(G, v, n): # 그래프 G, 시작점 v, 정점 개수 n
    visited = [0] * (n + 1) # 1. 방문 배열 초기화
    queue = []              # 2. 큐 생성
    
    queue.append(v)         # 시작점 enqueue
    visited[v] = 1          # 시작점 방문 표시
    
    while queue:            # 큐가 비어있지 않은 동안 반복
        t = queue.pop(0)    # dequeue (파이썬 리스트 pop(0)은 느리나 개념상 사용)
        print(t, end=' ')   # 방문한 정점 출력 (할 일 처리)
        
        for i in G[t]:      # t와 연결된 모든 인접 정점 i에 대해
            if not visited[i]:      # 아직 방문하지 않았다면
                queue.append(i)     # 큐에 넣고
                visited[i] = visited[t] + 1 # 방문 표시 (거리 기록)

# 데이터 세팅 (인접 리스트 방식)
V, E = 7, 8
edges = [1, 2, 1, 3, 2, 4, 2, 5, 4, 6, 5, 6, 6, 7, 3, 7]
G = [[] for _ in range(V + 1)]

for i in range(0, len(edges), 2):
    u, v = edges[i], edges[i+1]
    G[u].append(v)
    G[v].append(u) # 양방향 간선이라고 가정

print("BFS 탐색 경로:")
bfs(G, 1, V) # 결과: 1 2 3 4 5 7 6
